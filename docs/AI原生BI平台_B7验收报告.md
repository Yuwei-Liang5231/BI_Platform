## 五、已知问题与环境注意事项（不阻塞验收）

1. **WorkBuddy 环境特有**：WorkBuddy 托管 Python 进程内的 `unlink` 会被其安全删除守卫（sitecustomize shim）拦截，导致「删除数据集」时文件清理偶发 500（**DB 元数据已正确删除**，仅孤儿文件需手动清）。梁老师本机自行启动的后端进程不含该 shim，**不受影响**；首轮 smoke 的删除均为 200 可佐证。
2. **删除指标/数据集后前端残留选中态**：看板或详情仍停留在已删指标时取数返回 400（数据行为正确）。建议 B8+ 在删除成功后联动清理前端选中状态。
3. 本机 5175/5180 端口被安全策略拒绝监听（`EACCES`），联调 preview 改用 **5183**；`vite.config.js` 已补 `preview.proxy`（目标默认 8100，可用环境变量 `BI_BACKEND_ORIGIN` 覆盖）。
4. 测试残留（有意保留）：`b7_gmv`/`b7_gmv_r3`~`r8` 为软删状态（留痕可查），`b7_viewer_r3/r4` 为停用账号；均不影响目录与计算。

## 六、口径变更影响清单机制（验收要点）

1. **留痕**：`GET /api/metrics/{id}/changes` 返回按时间倒序的变更记录，每条含 before/after 快照、reason（必填，≥2 字）、操作人、时间——口径为什么改、谁改的、改了什么可完整追溯。
2. **存档 SQL**：`GET /api/metrics/{id}/sql` 返回当前版本的编译存档，与详情页折叠区一致；历史版本随 ver 保留。
3. **原子性**：改口径 → 重编译 → 存档 → ver+1 → 留痕在同一事务完成；编译不过（超纲算子）保存即拒绝，口径不被破坏。
4. **生效路径**：取数实时重编译 + 缓存键含 ver，ver+1 即旧缓存自然失效——无需重启，看板/详情刷新即新口径。

## 七、用户验看清单（梁老师操作步骤）

> 前置：Ctrl+C 重启 8100 加载最新代码（`.\scripts\bi.ps1 run -Env dev -Port 8100`）；前端 `npm run dev`（5173）或直接用现有 dev 页。

**① 一键回归（可选，约 1 分钟）**

```powershell
# 后端测试目录下
.\scripts\bi.ps1 test          # 期望 176 passed
# 服务启动后（bi-platform 目录）
..\..\.workbuddy\binaries\python\envs\default\Scripts\python.exe backend\scripts\smoke_b7.py 8100
# 期望 28 passed, 0 failed（幂等自愈：启动自动清理上次残留，
# code 被软删占用时自动换时间戳后缀并打印提示）
```

**② 浏览器端到端走查（约 5 分钟）**

1. 登录 `http://localhost:5173`（admin/admin123）
2. **数据集**：上传任一 CSV（如 `dataset_a/channels.csv`），确认编码/行数/字段预览
3. **指标管理**：从模板导入「电商零售」→ 新建指标（三模式计算规则编辑器选「简单聚合」）→ 试编译通过后保存
4. **指标目录**：搜索刚建的指标 → 点卡进详情 → 核对当前值、趋势图、口径说明、**变更历史**（本批修复点，应有记录而非空表）、折叠 SQL
5. **改口径全局生效**：在指标管理编辑该指标换一个过滤条件（填变更原因）→ 回详情页刷新 → 数值变化 + 变更历史新增一条带原因的记录
6. **看板**：切主题筛选，确认新指标卡片出现、点卡片不再触发下载、环比徽章颜色语义（绿↑/红↓）
7. **权限（可选）**：在指标管理对该指标登记 role=viewer 限制 → 换 viewer 账号登录确认目录与取数均不可见 → 清空限制恢复

**③ 视觉对照**：直角卡片、品牌橙仅强调色、Helvetica Neue 正文。
